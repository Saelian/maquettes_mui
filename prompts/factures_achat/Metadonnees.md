# Adaptation des données factices concernant les métadonnées

Cette demande concerne aussi bien la maquette FacturesAchatiXfacture que FacturesVenteIxfacture.
Elle est également en corrélation avec la maquette MetadonneesIXFacture.

Dans l'application, l'administrateur devra permettre à ses utilisateurs d'enrichir les factures avec des métadonnées complémentaires.
Le paramétrage de ces métadonnées par l'administrateur se fait par le biais de la maquette "MetadonneesIXFacture".

Il faut mettre en cohérence les données exemples de la maquette MetadonneesIXFacture avec celles des maquettes FacturesAchatiXfacture et FacturesVenteIxfacture. Ce qui est paramétré dans la première maquette doit être ce qui est affiché dans les factures exemples des deux autres menus.

Ce qui est actuellement paramétré dans la maquette MetadonneesIXFacture est correct. Utilise ces données et répercute les sur les factures qui sont dans les maquettes FacturesAchatiXfacture et FacturesVenteIxfacture
