# Consultation de l'annuaire

Cette demande concerne la création d'une nouvelle maquette "ConsultationAnnuaireIXFacture".

Cette maquette sera utilisée pour effectuer des recherches dans l'annuaire public de l'état concernant les entités qui ont acquis une plateforme agréée.

Cette maquette sera interfacée avec l'api dont tu trouveras la page dans le dossier ressources/api_iopole/directory_main

On doit pouvoir chercher dans l'annuaire international que tu trouveras dans ressources/api_iopole/directory_peppol.

Et on doit aussi pouvoir chercher dans l'annuaire français que tu trouveras dans le dossier ressources/api_iopole/directory_french.

Il faut prévoir un écran qui permet de choisir dans quel annuaire rechercher (annuaire français par défaut), puis les divers critères disponibles selon les documentations ci-dessus. 

Lorsqu'on lance la recherche, il faut retourner les résultats dans un tableau.

Cette maquette sera liée au sous menu "Annuaire" du module iXFacture.
